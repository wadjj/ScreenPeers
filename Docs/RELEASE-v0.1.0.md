# ScreenPeers v0.1.0 · 首个公开预览版

原生 macOS 菜单栏 VNC 来源监控，支持地址复制、设备备注、登录启动，以及 DNSPod / 阿里云 / 自定义适配器的可选 IPv4 DNS 更新。

## 下载和安装

- `ScreenPeers-v0.1.0-macos-arm64.zip`：Apple Silicon，macOS 13+。解压并将 App 拖入 Applications。
- `SHA256SUMS.txt`：下载包校验值。
- Intel Mac 可从源码构建，尚未实机验证。

预览包为 ad-hoc 签名，未做 Apple 公证。系统可能阻止首次打开，确认来源后可在“隐私与安全性”允许，或自行构建。DNS 功能需要另外安装 Python 3.9+；VNC 监控无需 Python。

## 已知范围

- 统计 TCP 5900 的不同来源 IP；高性能屏幕共享模式尚未完整覆盖。
- 发布本机主网络 IPv4，包括内网或 VPN 地址；不探测公网出口，不更新 AAAA。
- 阿里云真实账户、物理网络切换及长期运行尚未验证。
- 配置、密钥、个人设备信息和本机迁移记录均不包含在发布文件中。

## 本版验证

- 26 项 Python 测试通过，包括模拟服务商及自定义适配器端到端测试。
- 6 个原生网络选择场景、7 个原生连接解析场景通过。
- Apple Silicon 构建、App bundle 结构和代码签名校验通过。
- 发布源码及 App 包完成凭据和个人信息检查；仓库从清理后的首个提交开始。
